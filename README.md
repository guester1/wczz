# wczz 1.0-0

Independent WeChat tweak implementing the requested Group Helper and Red Detail behavior based on static analysis of the supplied MiYou binary and adapted to the supplied WeChat headers.

Runtime dependencies: none on MiYou or WCRefine.

Features:
- wczz master switch
- Group Helper with common-group whitelist
- optional top placement
- Group Helper + menu: one-click read / common-group management / cancel
- no clear-chat-history or delete-all-messages actions
- independent red-detail switch
- plugin-manager controller registration only; no separate plugin-manager switch
