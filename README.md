# wczz 1.0-0

Independent WeChat tweak implementing two behaviors adapted from static reverse-engineering of MiYou 3.9-5:
- Group Helper / common-group folding
- Red-envelope detail summary

Runtime dependencies: WeChat only. No MiYou/WCRefine runtime dependency.

Settings are stored in wczz-owned NSUserDefaults keys.

Build:
make clean
make package
